## 4. 유지할 평가 원칙

- 정식 첫 평가는 질문당 RAG 1회이며, 반복 안정성까지 검증했다고 해석하지 않는다.
- 실제 반환·전달 순서와 입력을 보존한다. 검색을 다시 수행해 당시 컨텍스트를 대신하지 않는다.
- Q07·Q08 검색 지표, Q07~Q10 Answer Relevancy는 적용 불가다. Q09·Q10 검색 reference는 답변 가능한 부분만 포함한다.
- Faithfulness는 사실 주장이 있는 실제 답변 전체에 적용한다. 순수 거절의 N/A와 사실 주장 추출 실패의 오류를 구분한다.
- 규칙은 대상과 값의 연결이 명확할 때 검사하고, 추출이 불안정하면 `undetermined`로 남긴다.
- 사람의 세 항목이 모두 통과해야 최종 통과다. 지표 점수·규칙·Judge·사람 판정은 각각 보존한다.
- 동일 답변 재평가에는 새 `eval_run_id`를 사용하고, 과거 RAG 비용을 이번 평가 비용에 재합산하지 않는다.
- 비용·시간에는 첫 평가의 합격 임계값을 두지 않는다.
