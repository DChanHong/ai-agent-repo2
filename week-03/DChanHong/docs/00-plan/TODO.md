## 4. 재개할 때 유지할 평가 원칙

- 첫 평가는 기존 RAG 동작을 유지하고 질문당 1회 실행한다. 개선·반복 평가부터 시작하지 않는다.
- 골든 정답·라벨·평가 기준을 검색 문서나 생성 입력에 넣지 않는다.
- 검색 순서는 정정 전 3개 → 정정 후 3개다. 전역 유사도 정렬로 바꾸지 않는다.
- 실제 생성에 전달한 컨텍스트를 보존한다. 나중에 검색을 다시 수행해 당시 입력으로 대신하지 않는다.
- Q07·Q08의 검색 지표와 Q07~Q10의 Answer Relevancy는 적용 불가다.
- Q09·Q10의 검색 기준은 답변 가능한 부분으로 제한하지만 Faithfulness는 실제 답변 전체에 적용한다.
- 사실 주장이 없는 순수 거절의 Faithfulness 적용 불가와 주장 추출 실패에 따른 평가 오류를 구분한다.
- 지표 점수, 규칙 검사, Judge, 사람 판정을 각각 보존한다. 사람의 세 항목이 모두 통과해야 최종 통과다.
- 동일 답변 재평가에는 새 `eval_run_id`를 발급하고 이전 자동 평가를 덮어쓰지 않는다.
- 비용·시간 허용 기준과 RAG 개선·재평가 여부는 첫 결과를 본 뒤 결정한다.
