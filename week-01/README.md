## 3. LLM 호출 실험

모델 하나를 골라 SDK로 직접 호출해보세요.
데이터와 작업은 자유롭게 정하고 지시·예시·생성 설정·출력 형식 등 궁금한 조건을 바꿔 실제 응답을 비교합니다. Temperature에 한정할 필요도 모든 항목을 실험할 필요도 없습니다.

실험에서는 아래 사항을 지켜주세요.

- **한 번에 여러 조건을 바꾸지 마세요.**
  - 비교하려는 조건 하나를 바꾸고 나머지는 유지해주세요.
  - 대화 이력을 실험하는 경우가 아니라면 이전 응답을 다음 요청에 붙이지 마세요.
- **요청이 성공했다고 설정이 적용됐다고 단정하지 마세요.**
  - 공식 문서에서 모델과 API의 지원 여부를 확인해주세요.
  - 추론 모드 등에 따라 전달한 값이 무시될 수 있습니다.
- **응답 한 건만 보고 결론 내리지 마세요.**
  - 같은 조건으로 반복 호출해보세요.
  - 각 조건에서 3회씩을 권장하며 실제 반복 횟수를 기록해주세요.
- **예상한 차이를 억지로 찾지 마세요.**
  - 차이가 없거나 예상과 달라도 그대로 정리하면 됩니다.
  - 이번 실험만으로 모델의 전반적인 성능을 단정할 필요는 없습니다.
- **API 키, 개인정보, 비공개 업무 자료는 제출하지 마세요.**
  - 공개 가능한 데이터로 진행해주세요.

사용한 모델과 SDK, 입력, 바꾼 조건과 유지한 조건을 실제 응답과 함께 남겨주세요.
오류나 중간에 끊긴 응답도 기록하고 관찰한 점은 실험별 3~5줄로 정리해주세요.
완료 기준은 **조건을 통제하고 실제 결과를 관찰했다**입니다.
