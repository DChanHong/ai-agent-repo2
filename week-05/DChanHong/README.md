# DChanHong의 5주차 과제

[공개 API 기반 AI Agent 과제 안내](../README.md)

## 개발 환경

저장소 루트에서 다음 명령으로 Python 환경을 준비합니다.

```bash
cd week-05/DChanHong
uv sync
```

실행 진입점은 `main.py`입니다.

## 과제 작성 항목

- Workflow와 Agent의 차이, Agent Loop, ReAct, 목표 달성 기준
- Agent의 목표와 Instructions, 공개 API 공식 문서, 환경변수 이름
- 모델이 다음 행동을 선택한 지점과 RAG 연결 여부 및 이유
- 요청 유형별 실행 기록과 목표 달성 판정
