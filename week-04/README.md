# Advanced RAG 개선과 평가 비교 과제

지난주 구성한 RAG와 평가 결과를 바탕으로 개선할 문제를 찾습니다.
Advanced RAG 고도화 방법을 직접 조사하고 서로 다른 기법 2개를 각각 적용해 기존 RAG와 비교해주세요.

## 1. 기존 평가 검토·보완

지난주 사용한 데이터, 평가 질문과 실행 결과를 이어서 사용합니다.
사람이 원문·검색 결과·답변을 대조하고 자동 평가가 적절하게 판단했는지 확인해주세요.

- 기대 답변과 근거는 정확하고 충분한가요?
- 성공·실패 기준은 구체적인가요?
- 선택한 지표가 확인하려는 문제를 측정하나요?
- 사람 판정과 자동 평가가 다르다면 무엇 때문인가요?

문제가 발견되면 평가 질문, 기대 답변, Rubric 또는 지표 적용 방식을 보완합니다.
문제가 없다면 기존 평가를 유지한 이유를 설명해주세요.

보완한 평가 기준은 기법 적용 전에 정하고 이후 세 구성에 동일하게 적용합니다.

## 2. Advanced RAG 고도화 방법 조사·선택

기존 결과에서 개선할 문제를 고르고 이를 해결할 수 있는 Advanced RAG 방법을 각자 조사해주세요.
실패가 없었다면 지난주에 확인하지 못한 상황이나 지연·비용 문제를 개선 대상으로 정합니다.
조사한 방법 중 **서로 다른 기법 2개**를 선택합니다.

각 기법에 대해 다음 내용을 정리해주세요.

- 어떤 문제를 해결하려는 기법인가요?
- RAG의 어느 단계에서 어떻게 동작하나요?
- 본인의 데이터와 개선 대상에 적합하다고 판단한 이유는 무엇인가요?
- 적용하면 검색 결과와 답변이 어떻게 달라질 것으로 예상하나요?
- 추가 비용·지연이나 새로운 실패 가능성은 무엇인가요?

참고한 자료의 링크와 선택 근거를 기록합니다.
같은 기법의 설정값만 바꾼 두 실험은 서로 다른 기법 2개로 세지 않습니다.

## 3. 세 구성 구현·실행

기존 RAG를 기준선으로 두고 두 기법을 각각 독립적으로 적용합니다.

| 구성 | 내용 |
|---|---|
| 기준선 | 지난주 RAG |
| 개선 A | 기준선에 기법 A 적용 |
| 개선 B | 기준선에 기법 B 적용 |

개선 B는 기준선에서 시작합니다.
A와 B를 함께 적용하는 조합 실험은 선택 사항입니다.

비교할 문서·평가 질문·판정 기준은 동일하게 유지합니다.
선택한 기법과 관계없는 설정은 가능한 한 고정하고 함께 변경해야 했던 조건이 있다면 이유를 기록해주세요.

## 4. 같은 기준으로 결과 비교

세 구성에 같은 평가셋·Rubric·지표를 적용합니다.
평가 기준을 보완했다면 기존 RAG 결과도 보완한 기준으로 다시 평가해주세요.
질문을 추가한 경우에는 세 구성 모두 해당 문항을 실행합니다.
지난주 기록에 실행 시간·호출 수가 없다면 기준선을 다시 실행해 기록합니다.

문항별로 다음 내용을 비교합니다.

- 검색된 근거와 실제 생성 모델에 전달한 컨텍스트
- 최종 답변
- 선택한 평가 지표와 판정 이유
- 원문을 대조한 사람의 판정
- RAG 실행 시간, 검색·모델 호출 수와 확인 가능한 비용

평가용 호출과 비용은 RAG 실행 기록과 구분합니다.

대표 실패 문항과 기존 성공 문항을 함께 확인합니다.
적용 불가와 실행 오류는 사유를 기록하고 품질 점수에 임의로 0점을 넣지 않습니다.
비교표에는 집계에 포함한 문항 수를 함께 적습니다.

## 5. 개선 효과와 적용 여부 판단

두 기법의 결과를 보고 다음 내용을 설명해주세요.

- 예상한 변화가 실제로 나타났나요?
- 어떤 문항이 개선됐고 어떤 문항이 나빠졌나요?
- 점수 상승이 실제 답변의 개선과 일치하나요?
- 추가 지연·호출·비용을 감수할 가치가 있나요?

각 기법을 **유지·수정·제거** 중 하나로 판단하고 근거를 작성합니다.

성능이 좋아지지 않았어도 괜찮습니다.
관찰한 결과를 바탕으로 효과와 한계를 설명할 수 있어야 합니다.
